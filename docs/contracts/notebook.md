# 约定：笔记本的布局和页的写法

学习模块（`src/learning/`）读角色的笔记本。这一页写它认什么。角色的笔记本照这页搭，学习就能扫到、能联想、能记分。
这页由学习维护；代码里的出处写在每条后面，改了代码要同步改这页。

学习对笔记本**只读**，只有一个例外：给没编号的页和教训发编号时，在那一行末尾补一段 HTML 注释（`ids.ts`）。

## 一、在哪

- 角色自己的页放在工作区里它自己的本里。HH 的模块带来的手册（书架上指到 HH 代码目录里的那些）对角色只读：不往里加页、不改，部署时会被换掉。

- 根目录是配置 `learning.root`（相对工作区）。下面说的路径都相对这个根。
- 书架的规矩文件：`learning.shelfFile`，默认 `shelf.json`，放在根目录。可以没有。
- 纠正的词表：`learning.correctionKindsFile`，默认 `corrections.json`，放在根目录。可以没有。（读它的代码还没上线，在分支 learning-live 上等着；这一条先写在这里。）

## 二、目录怎么排

```
<根>/
  shelf.json                 可选
  corrections.json           可选
  <常驻单子>                  可选，文件名是配置 `learning.residentFile`（默认值在语言包里，中文是「常驻.md」）
  <大类>/
    <本>/
      SKILL.md               这本的封面，必须有
      CHANGELOG.md           可选，不算页
      <页>.md                一页
      <归档目录>/…            这本里归档的页
    <归档目录>/…              这个大类里归档的页
  <归档目录>/…                整个书架归档的页
```

- 三层：大类、本、页。页的相对路径形如 `<大类>/<本>/<页>.md`。
- **一本必须有 `SKILL.md`**。没有的话这本不算，里面的页也不进联想，扫描时记一条问题。`SKILL.md` 开头的 frontmatter 里 `description` 是这本的简介，书架目录用它。
- `SKILL.md`、`CHANGELOG.md` 不算页。
- 本里别的子目录（脚本、素材）不算页，不往下扫。
- 直接带 `SKILL.md` 的大类目录当成旧的一层手册，整个跳过。
- 以 `.` 开头的目录跳过。
- 归档目录的名字是配置 `learning.archiveDir`（默认值在语言包里，中文是「归档」）。路径上任何一层叫这个名字的，下面的页都算归档：照样扫、编号照样认，但不进联想，归档里的本不上书架目录。
- 有一个大类算「通用」（配置 `learning.generalCategory`，默认值在语言包里）。联想给它单独的名额。

代码：`notebook.ts` 的 `scanShelf`、`pageFiles`。

## 三、一页怎么写

```markdown
# 标题 <!-- p:0123 -->
简介：一两句话，这页讲什么。
什么时候翻：什么情形下该翻这页。

## 做法
- 第一条做法
- 第二条做法

### 待验证
- 还没验证过的做法

## 教训
- 教训：做错了什么｜什么时候：什么情形｜下次：下次怎么做｜犯的日子：2026-11-04、2026-11-07｜出处：#12345｜强度：4 <!-- l:0456 -->
```

- 第一个 `## ` 之前是开头：`# ` 那行是标题，「简介：」「什么时候翻：」各一行。没写标题就用文件名。
- 页的编号在标题行末尾的注释里：`<!-- p:四位以上数字 -->`。并进来的旧编号接在后面，第一个是它自己的。没有编号的页不进联想，等发号。
- `## 做法` 下面的列表是做法。开始做一件事时，联想把头几条直接贴出来。`### 待验证` 下面的最外一层条目数是「待验证」的条数。
- `## 教训` 下面，每行一条，以「教训：」开头的列表项才算。字段用全角竖线 `｜` 隔开，每段以「名字：」开头：
  - 教训、什么时候、下次（或「怎么做」）、犯的日子、出处、怎样算做到、强度、提醒。
  - 「犯的日子」用顿号或逗号隔开，认 `YYYY-MM-DD` 开头的；括号里的说明不算日子。
  - 「出处」里的 `#数字` 是消息的编号。
  - 「强度」0 到 5，没写按 3 算。到参数 `strength.strongMin` 的算强教训，会大声提醒；5 是常驻候选。
  - 「提醒」只认两种，可以一起写：「动手时」（也认「动手」「动手那一下」；只在看得出这一步就要做时才提醒）、「发之前」（也认「发前」「发给某某之前」；发给主人之前那道核对用）。写了别的字，这一段不当「提醒」认。
  - 教训的编号在行末：`<!-- l:四位以上数字 -->`。没编号的教训不进联想。
- 代码块（三个反引号或波浪线围起来的）里的内容都不认。
- 手写的页难免不全。解析从不报错：缺的字段是空的，读不了的文件记进扫描的问题单。

这些字段名和记号是代码要认的记号，在语言包里（`src/lang/<语言>/brain.ts` 的 `forms.page`），一个语言一份；上面写的是中文包的样子。英文包的是：开头两行 `Summary:`、`When to open:`，两节 `## Practices`（小节 `### To verify`）、`## Lessons`，教训一行的字段 `Lesson | When | Next time | How | Done when | Days | Sources | Strength | Remind`（用 `|` 隔开，提醒写 `when starting`、`before sending`）。`hh learn format` 给出的是当前角色那一份。

代码：`notebook.ts` 的 `parsePage`、`parseLesson`、`pageItems`、`practiceHead`。

## 四、页和页之间的线

学习每晚重算三种线（`graph.ts`），存在库里，不改页：

- 页里提到别的页：`[[页名]]`、markdown 链接、反引号里的路径、正文里出现的 `<文件名>.md`。同名不止一页的只认路径。
- 同一件事里挨着翻开过的两页。
- 事件库同一件事的经过里一起写到的页。

## 五、可选的三个文件

**`shelf.json`**（哪些页算重要，`layers.ts`）

```json
{ "importantMarks": ["页里出现这个记号就算重要"], "importanceKey": "importance" }
```

页的重要度：页开头十二行里有一行 `<importanceKey>：数字`（0 到 5）的，以写的为准。没写的从 3 起，取这几样里最高的：有教训在常驻单子里（5）、页里最强那条教训的强度、页里出现 `importantMarks` 里的记号（4）。4 以上算重要，不会被放到深层。

**常驻单子**（`shelf.ts`）

一个列表，每个列表项是一条她要每一轮都记着的话，原样放进她的开头；项里可以带教训的编号（`l:0456`），夜里的工作单靠它知道哪条教训在常驻。只取前几条，几条看参数 `strength.residentMax`。没有这个文件或文件是空的，就按强度 5 的教训列。

**`corrections.json`**（纠正的词表，`kinds.ts`；还没上线）

```json
{ "kinds": [ { "name": "这一类叫什么", "pattern": "认这一类的正则", "page": "照着做的页，相对根目录", "examples": "记例子的页，相对根目录" } ] }
```

主人的话对上某一类的 `pattern`，就算一次纠正，并提醒她把这一对例子记进 `examples` 那页。路径不许跳出根目录。写坏的那一类跳过，别的照用。

## 六、学习写到笔记本外面的东西

- `<状态目录>` 下的库：联想记录、翻开记录、编号、线、参数。
- `<状态目录>/learn/weekly.md`：每晚重写的一周数字。
- 夜里整理的报告末尾追加「笔记分层」一节（路径现在写死成 `<工作区>/sleep/<日子>/report.md`，要改成配置）。
