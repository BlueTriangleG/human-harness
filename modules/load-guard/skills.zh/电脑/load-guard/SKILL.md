# 电脑负载（load-guard）

## 是什么
这台电脑的内存是你和别人共用的。负载把关每分钟看一次内存（压缩区、交换区、从硬盘换回的速度、系统压力、可用内存、磁盘余量、有没有冻住过），写下状态，并且在电脑快要卡死的时候替你减负。它只防死机：没到危险线，电脑随你用。

## 三档
- **正常**：随便用。
- **偏紧**：只是提醒，不拦任何事。留意别同时开好几样重的。
- **危险**：再开新东西可能把整台电脑冻住。这时不开新的重活（包括自动开手机），先收尾、关掉不用的。

## 命令
- `load`：现在怎样，一行。后面还说开重活前还有多少余量。
- `load gate <种类>`：开工前的闸。种类是 `phone`（手机模拟器）、`cc`（新开或接着一轮帮手会话）、`heavy`（视频、音频、批处理）；只改代码的轻活用 `cc-light`。退出码 0 放行，1 不放行，并说为什么。
- `load room <种类>`：你自己要开东西时用。够就放行；不够先关能放心关的，还不够就列出你占内存的进程，你自己决定关哪个。
- `load json`：同 `load`，给程序读的。
- `load events`：还没报过的减负事件（感官用，你一般不用）。

## 自动减负
- 同一台机器上只有一个角色的负载看守会减负；配置里 `shed: false` 的只看不减。
- 碰到比「危险」更靠近死机的那条线、连着几分钟（系统内存压力到最高一级时立刻），巡检一次只做一步：先关手机（之后半小时不会自动重开手机），手机关着就结束你占内存最大的那个可关的重活进程（视频处理、脚本、浏览器这类）。常驻的服务不碰，别人的进程不碰。
- 做了什么会叫醒你说明。
- 那条线持续好几分钟、你这边已经没东西能关（占内存的在别人那边），它会通知你的主人，几小时最多一次。

## 常见的坑
- 闸门不放行不等于停工：先关自己闲着的东西，再换低内存的做法（一次一件、分段串行、限线程），别反复等同一个重方案放行。
- 被自动关掉的东西别马上重开，先想是哪件事太重。
- 重活一件一件来：手机和视频处理别同时开，同一时间只跑一个大的音频或视频处理，帮手和你自己算在一起。
- 只关属于你自己的进程；别人的、拿不准的，告诉主人。
- 别为了开工去改阈值、手工扩交换区。
