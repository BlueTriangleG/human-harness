# 装模拟器（第一次用之前，一般是主人或运维来装）
简介：第一次用手机之前把安卓模拟器装起来：装安卓 SDK、下系统镜像建一台手机、在配置里告诉 HH 用哪台、第一次开机和登录。
什么时候翻：`phone-start` 说还没配模拟器、要新建或重建一台手机的时候。

1. **装安卓 SDK**：装 Android Studio，或者只装命令行工具，SDK 默认在 `~/Library/Android/sdk`（放在别处就设环境变量 `ANDROID_HOME`）。要有 `platform-tools`（里面有 `adb`）和 `emulator` 两样：`sdkmanager "platform-tools" "emulator"`。
2. **下系统镜像、建一台手机**：苹果芯片的 Mac 用 arm64 的镜像。
   - `sdkmanager "system-images;android-34;google_apis;arm64-v8a"`
   - `avdmanager create avd -n <名字> -k "system-images;android-34;google_apis;arm64-v8a" -d pixel_6`
   - `emulator -list-avds` 能看到这个名字就建好了。镜像和数据一台要十几 GB，系统盘紧就把 `~/.android/avd/<名字>.avd` 挪到外置盘、原处留一个链接。
3. **告诉 HH 用哪台**：实例配置里写 `"modules": { "phone": { "enabled": true, "avd": "<名字>" } }`；要换端口、内存（MB）、不开窗口就加 `port`、`memoryMb`、`"window": false`。`hh modules check phone` 显示「好」就行。
4. **第一次开机**：`phone-start`。开好以后在模拟器里登录要用的应用（扫码、短信验证码都由人来做），关掉不用的预装应用能省不少内存。
5. **想在电脑上看着它**：模拟器默认开着窗口；或者装 `scrcpy` 投屏。
