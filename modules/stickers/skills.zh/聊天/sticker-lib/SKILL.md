# 表情包库（sticker-lib）

## 是什么
一个放在你工作区里的表情包库（默认 `stickers/`）：`index.json` 记每张的名字、描述、情绪词、标签、给谁用、评分、用过几次和对方的反应；`img/` 是收好的图，`inbox/` 是还没决定的候选，`trash/` 是删掉的（能找回来）。

## 发
- 用 **sticker 工具**，不用命令：`mood` 写情绪词（「开心」「无语」「收到」这样，可以几个），它按匹配度、评分、对方的反馈挑一张，最近刚发过的少挑；`ref` 指定发哪几张（库里的 id，或库目录里的图片路径）。
- 默认发给正在跟你聊的人；发给别人写 `to`。
- 发 WhatsApp 时 GIF 会自动转成能循环的视频。
- 没有匹配的会告诉你最接近的几个情绪词，换个词再试，或者这次不发。

## 找新的、收进库
1. 找：`sticker categories` 看有哪些情绪分类；`sticker browse <分类> -n 3` 按分类下几张候选；`sticker search <番名或角色> -n 3` 按作品找；`sticker grab <图片网址>` 收一张你在别处看到的。都下到 `inbox/`。
2. 审：`sticker inbox` 列出候选，一张张看过（真的打开图看）。
3. 收：`sticker add <候选路径> --name <短名> --desc <画面里是什么、什么场合用> --moods <情绪词,逗号分隔> [--tags …] [--for me|<主人的名字>|both] [--rating 1-5] [--source …]`。情绪词写你聊天时真会想到的词，描述写清楚画面，以后才挑得准。
4. 不要的：`sticker reject <候选路径…>`。

## 整理
- `sticker find <词…>` 在库里搜，`sticker pick <情绪词>` 试挑一张（不发）。
- `sticker edit <id> --moods … --desc … --rating …` 改；`sticker remove <id> --reason …` 移到 trash。
- `sticker feedback <id> liked|disliked [--note …]` 记对方的反应：喜欢的以后多挑，被嫌弃两次又没人喜欢的不再挑。
- `sticker stats` 看总数、候选数、最常用的、被嫌弃的。

## 每周收一次
表情包模块每周提醒你一次收新表情。到了就按上面「找新的」做几张；不想收就跳过。

## 常见的坑
- 收之前先看图：缩略名和网址看不出画面，收错了挑图时会发出奇怪的。
- 情绪词别写太偏：没人会想到的词等于没写。
- 库别越收越大：常用的留着，从来没发过又不喜欢的清掉。
- 超过 5MB 的图下载时就会被拒：表情包用不着那么大，换一张小的。
