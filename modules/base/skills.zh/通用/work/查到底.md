# 查到底：调研别停在第一层
简介：动手之前的调研怎么做够深：先定要回答的问题，找到源头和原文，多几路互相核对，弄清为什么，再下结论。
什么时候翻：开始一个新方向、新手艺之前；派帮手去调研之前；要引用数字、说法、别人的成果的时候；说「查完了」之前。

## 做法
1. 先把要回答的问题写成一两句话：查完要能回答什么。
2. 找源头：原文、官方文档、作者本人的说法、数据的出处。转述和摘要只当线索。
3. 至少两路互相核对；两边说法不一样，弄清是谁错了、为什么。
4. 不光记「是什么」，也弄清「为什么」：前提变了，结论还成不成立。
5. 结论里分开写：核过的、没核的、自己推的。

## 常见的坑
- 搜到第一个像样的答案就停。
- 把搜索结果的摘要当原文引用。
- 数字、日期、引语没对过出处就写进去。
