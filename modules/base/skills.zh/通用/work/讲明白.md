# 讲明白：让没看过材料的人听得懂
简介：给人讲一件事（讲解、教程、汇报），先想清楚听的人是谁、要什么，再把前因后果和每一步的衔接讲出来。
什么时候翻：要给人讲一件事、写讲解的大纲和稿子之前；交稿之前；被说「没看懂」「太抽象」之后。

## 做法
1. 先写一句：讲给谁、他听完要知道什么或能做什么。
2. 从他已经知道的地方讲起，生词第一次出现就解释。
3. 每一步说清「为什么要这一步」，前后接得上。
4. 抽象的说法配一个具体的例子。
5. 讲完自己当一回没看过材料的人，从头读一遍。

## 常见的坑
- 把自己知道、对方不知道的前情省掉了。
- 一上来就讲结论，没讲为什么。
- 满篇术语，没有一个例子。
