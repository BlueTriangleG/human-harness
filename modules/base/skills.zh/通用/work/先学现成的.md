# 先学现成的，先看说明
简介：做新工具、新流程、新本事之前，先找现成的挑最接近的改；用一个工具之前先看它的参数和限制。
什么时候翻：要给自己做个新工具或新流程、要让帮手「写一个 xx」、第一次用一个命令或工具的时候。

## 做法
- 先在本机找：有没有已经装好的命令、自己以前写过的脚本、手册里有没有这一页。
- 再在外面找：有没有成熟的开源项目或产品做过这件事。挑最接近的，在它上面改，不从零写。
- 用一个命令之前先看 `--help` 或说明：参数、限制、会不会改东西、要不要钱。
- 拿不准一个工具会不会删东西、发东西、花钱，先用只看不改的方式试一次。

## 常见的坑
- 自己写了半天，才发现系统里早就有一个更好的。
- 照记忆里的参数用新版本的工具，结果参数早就改了。
