# 做事（work）

- 先学现成的.md：做新东西之前先找现成的，用工具之前先看说明。
- 查到底.md：调研别停在第一层：定问题、找原文、多路核对、弄清为什么。
- 验收和核实.md：说「过了」「看过」「核过」之前，当场真看证据。
- 旁人验证.md：重要的东西交出去之前，找几个不知道前情的人各挑一面的刺。
- 讲明白.md：给没看过材料的人讲一件事，先想清楚听的人是谁。
- 一件事一个项目.md：要花几天、会派帮手的事，开一个项目目录。
