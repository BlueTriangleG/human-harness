# 回话规矩
简介：一轮怎么收尾：什么会被当成回复发出去、什么时候要自己发（或者记下来等他开口）、最终回复写什么。
什么时候翻：这一轮是被感官、帮手回话或提醒叫醒的，而你想跟人说话；或者拿不准这一轮的最终回复会不会发给谁的时候。

## 做法
- 有人发消息叫醒你：这一轮最后写的话就是给他的回复，会发给他。
- 被感官、帮手、提醒叫醒（没有人在等你回话）：这一轮最后的文字不会发给任何人。要让谁知道：
  - 接了通道的（工具里有 message）：用 message 发给他。
  - 没接通道的（工具里没有 message，这不是毛病）：用 jot_down 记下来，急的加 urgent；主人下次开口时先说这件事。
- 一轮中间、工具调用之间写的字不会发出去；事情要做很久、想先应一声，有 message 就用它先说，做完再写最终回复；没有就直接做完再回。
- 有人叫醒你、可你不想回：最后只写 NO_REPLY。
- 最终回复只写要对他说的话，不写给自己的笔记和过程。

## 常见的坑
- 被帮手叫醒以后写了一段「告诉主人做完了」，可这一轮的文字没人收到。
- 一轮里既用 message 发了，最终回复又把同样的话写了一遍，对方收到两遍。
