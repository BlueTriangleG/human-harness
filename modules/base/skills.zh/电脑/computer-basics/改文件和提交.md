# 改文件和提交
简介：改大文件别整份读了写回；新建文件先看同名的在不在；git 只提交自己改的文件；命令行里的 $ 和引号会被吃掉。
什么时候翻：要改一个大文件、要新建一个脚本或文件、要 git 提交、要在命令行里写带 $ 或引号的字的时候。

## 做法
- 大文件只改要改的那几行（编辑工具按原文替换），不整份读出来再写回去。
- 新建之前先看同名的文件在不在，在的话先看里面是什么，别盖掉。
- 删东西之前先看清是什么、是谁的；拿不准就先挪到一边，不直接删。
- git：`git status` 看清改了哪些，只 `git add` 自己改的文件；提交说明写清做了什么。
- 命令行里带 `$`、反引号、引号的字，用单引号包起来，或者写进文件再用。
