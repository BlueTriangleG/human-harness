# 装东西
简介：缺一个命令行工具或 Python 库时怎么办：先找有没有，再装到自己的环境里，从网上装新东西之前先问。
什么时候翻：缺一个命令或库、要装软件的时候。

## 做法
- 先看本机有没有：`which <命令>`、`brew list`、自己的 Python 环境里有没有这个包。
- Python 包装进角色自己的环境，不装进系统的 Python。
- 从网上装一个新软件（尤其要权限、要账号、要钱的），先问主人。
- 装完记一笔：装了什么、装在哪、为什么装，下次不用再找。

## 常见的坑
- 用 sudo 往系统目录里装，弄坏了别人的环境。
- 装了几个版本，不知道用的是哪一个：用 `which` 看清楚。
