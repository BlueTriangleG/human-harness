# To the bottom: research does not stop at the first layer
Summary: How to research deeply enough before acting: first set the question to answer, find the origin and the source text, check several ways against each other, understand why, and only then conclude.
When to open: Before starting in a new direction or a new craft; before sending a helper to research; when about to quote a figure, a claim or someone's result; before saying "I have looked into it".

## Practices
1. First write the question to answer in a sentence or two: what must the research be able to answer when it is done.
2. Find the origin: the source text, the official documentation, what the author says, where the data comes from. Retellings and summaries are leads only.
3. Check at least two ways against each other; where they disagree, find out which is wrong and why.
4. Note not only what is so but why: if the premises change, does the conclusion still hold.
5. Keep apart in the conclusion: what was checked, what was not, what you inferred yourself.

## Common pitfalls
- Stopping at the first decent-looking answer the search gives.
- Quoting the search result's summary as if it were the source.
- Putting in figures, dates and quotations without checking them against their source.
